# Quantum Advantage Suite

This folder contains the final quantum-enhanced fusion analysis script:

- `run_quantum_advantage_suite.py`

The script covers:

- Experiment 9: quantum-enhanced fusion against a strong fusion reference
- Experiment 10: operating-point metrics such as sensitivity, specificity, F1, calibration, and DCA
- Experiment 11: hard-case and boundary-case complementarity analysis

The public repository includes the script only. Required prediction CSV inputs and generated result files are not redistributed.
