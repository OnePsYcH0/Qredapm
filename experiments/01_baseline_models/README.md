# Baseline Models

This folder contains basic baseline and CPU tuning scripts:

- `train_baseline.py`: structured baseline
- `train_text_baseline.py`: text baseline
- `train_weak_baseline.py`: weak structured baseline
- `train_weak_text_baseline.py`: weak text baseline
- `run_cpu_baseline_tuning_audit.py`: tuned HGB, logistic fusion, and weighted-average fusion audit

Raw data and generated prediction files are not included.
